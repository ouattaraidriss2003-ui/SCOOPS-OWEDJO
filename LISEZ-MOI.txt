SCOOPS OWEDJO — Boutique + administration sécurisée (Firebase)

FICHIERS : index.html (boutique), admin.html (administration), shop.js, admin.js,
firebase-config.js, firestore.rules.

INSTALLATION (une seule fois)
1. Créez un projet Firebase sur https://console.firebase.google.com/.
2. Ajoutez une application WEB et copiez ses paramètres dans firebase-config.js.
3. Dans Authentication > Sign-in method, activez Email/Password.
4. Dans Authentication > Users, créez manuellement votre compte administrateur.
   Ne créez PAS de page d'inscription publique.
5. Copiez l'UID de ce compte (Authentication > Users).
6. Dans Firestore Database, créez une base en mode production.
7. Dans Firestore > Rules, collez firestore.rules et remplacez REMPLACER_UID_ADMIN
   par votre UID exact, puis cliquez sur Publish.
8. Dans firebase-config.js, renseignez votre numéro WhatsApp au format 225XXXXXXXXXX.
9. Publiez TOUS les fichiers ensemble sur un hébergement HTTPS (ex. GitHub Pages).
10. Ouvrez https://votre-site/admin.html, connectez-vous, puis créez vos produits et annonces.

IMPORTANT
- Ne partagez jamais votre mot de passe ni une clé de compte de service Firebase.
- Les paramètres de l'application WEB Firebase sont publics : la sécurité repose sur
  Firebase Authentication et les règles Firestore, pas sur le secret de l'URL admin.
- Avant configuration, le site affiche seulement des produits de démonstration.
- Une fois des produits ajoutés, le catalogue public bascule sur les produits réels.
- Si vous supprimez tous les produits, la démonstration réapparaît : ne publiez pas
  une boutique vide avant d'avoir renseigné votre catalogue réel.
- Les annonces sont mises à jour en temps réel pour les visiteurs ayant la page ouverte.
  Ce ne sont PAS des notifications push système sur les téléphones.
- Les images des produits utilisent une URL HTTPS : l'upload de fichiers n'est pas inclus.
- Les commandes passent par WhatsApp : il n'y a ni paiement en ligne ni suivi de stock.
- Ouvrir index.html en double-cliquant peut bloquer les modules ES : utilisez un serveur
  local ou le site HTTPS publié pour tester.
- Firebase peut imposer des limites d'utilisation et des frais selon le plan et le trafic.
